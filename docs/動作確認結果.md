### 日本時間への統一後の再実行

2026年11月9日、同梱の自動テスト18件を再実行し、すべて成功しました。実行環境はLinux、Python 3.12.14、Flask 3.1.3、SQLite 3.53.1です。

追加で、協定世界時ではまだ前日となる日本時間の午前0時の前後を再現し、当日の試合が「今後の試合」に含まれること、日付が切り替わると前日の試合が「過去の試合」に移ることを確認しました。両表示の並び順も確定仕様書どおりでした。

### 再実行コマンド

アプリのルートフォルダで実行する。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
