# フォルダ構成

最上位フォルダは `SougeiShare-v2/` です。

| 場所 | ファイル | 用途 |
| --- | --- | --- |
| SougeiShare-v2/ | app.py、database.py、schema.sql | Python処理とDB定義 |
| SougeiShare-v2/ | requirements.txt、README.md、README.html、design.html、.gitignore | 依存・手順・ブラウザー用案内・除外設定 |
| templates/ | base.html、_account_fields.html | 共通レイアウト・入力欄 |
| templates/ | login.html、group_create.html、group_join.html | ログイン・新規登録 |
| templates/ | match_list.html、match_register.html、history.html、error.html、account_withdraw.html、group_delete.html | 試合・履歴・エラー画面 |
| static/css/ | style.css | スマホ・PCの表示調整 |
| static/js/ | app.js | 確認メッセージ・曜日プレビュー |
| docs/ | 確定仕様書.md、詳細設計.md、フォルダ構成.md、動作確認結果.md | 設計と検証資料 |
| docs/ | 01・02・03・04・06・10・11の.mmd、設計図一式.md | Mermaid設計図の正本とリンク集 |
| docs/diagrams/ | 01・02・03・04・06・10・11のPNG | 閲覧用の設計図画像 |
| image/ | image-1.png～image-7.png | READMEの画面画像 |
| tests/ | test_app.py | 一時DBを使う自動テスト |
| instance/（起動時に生成） | sougeishare_v2.db、secret_key | データとローカル用秘密値 |
| .venv/（利用者が作成） | Pythonとライブラリ | アプリ専用の仮想環境 |

instance/、.venv/、__pycache__/は配布用ソースには含めません。
